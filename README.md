# Вальдмарк — живой средневековый город

Браузерная песочница-симулятор: средневековый город живёт сам по себе, а вы — невидимый наблюдатель с камерой, который может вмешиваться: отдавать приказы жителям и насылать бедствия. Полностью офлайн, один файл.

## Запуск

Откройте `dist/index.html` двойным кликом — сервер и интернет не нужны.

## Сборка из исходников

```
npm install
npm run build      # typecheck + сборка в dist/index.html
npm test           # headless-прогон симуляции (10 игровых дней на нескольких сидах) с проверкой инвариантов
DAYS=3 LARGE=1 npm test   # короче и с большим городом
npm run dev        # dev-сервер Vite
```

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` / стрелки / перетаскивание мышью | камера |
| колесо | зум |
| пробел | пауза |
| `1`–`4` | скорость 1×/2×/4×/8× |
| `F` | следовать за выбранным жителем |
| `M` | рынок и казна (цены, запасы, ползунок налогов) |
| `G` | божественные силы (бедствия, милости, налоги, стража) |
| `T` | статистика и графики |
| `O` | оверлей карты (преступность / риск пожара / богатство) |
| `H` | камера на площадь |
| `Esc` | снять выделение / отменить выбор цели |

Клик по жителю — пауза и карточка (потребности, черты, деньги, семья, отношения, память, биография, приказы). Клик по зданию — карточка здания. Клик по событию в хронике — камера переносится к месту.

## Структура кода

- `src/core` — ГПСЧ, шум, время, математика
- `src/world` — тайлы, здания, генератор города, A*, пространственный хеш
- `src/sim` — жители, население, расписание, движение, потребности, преступность, пожары, здоровье, погода, живность, события города, стройка и рост, божественные силы
- `src/ai` — действия и utility-выбор, разговоры и реплики, приказы
- `src/economy` — товары, рецепты, рынок, деньги, налоги, торговля
- `src/events` — хроника
- `src/render` — камера, тайлы по чанкам, процедурные спрайты, освещение, погода, оверлеи
- `src/ui` — стартовый экран, HUD, карточки, панели, миникарта
- `src/save` — сериализация, IndexedDB, экспорт/импорт
- `test/headless.ts` — headless-тест
