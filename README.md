# Вальдмарк — живой средневековый город

Браузерная песочница-симулятор: средневековый город живёт сам по себе, а вы — невидимый наблюдатель с камерой, который может вмешиваться: отдавать приказы жителям и насылать бедствия. Полностью офлайн, один файл.

## Запуск

Откройте `dist/index.html` двойным кликом — сервер и интернет не нужны. На стартовом экране — название города (сид), размер карты (малая 160×160, средняя 224×224, большая 320×320 тайлов) и галочка «туман войны» (окрестности открываются по мере разведки).

## Сборка из исходников

```
npm install
npm run build      # typecheck + сборка в dist/index.html
npm test           # headless-прогон симуляции (10 игровых дней на нескольких сидах) с проверкой инвариантов
DAYS=3 LARGE=1 npm test   # короче и с большим городом
npm run dev        # dev-сервер Vite
```

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` / стрелки / перетаскивание мышью | камера |
| колесо | зум |
| пробел | пауза |
| `1`–`4` | скорость 1×/2×/4×/8× |
| `F` | следовать за выбранным жителем (внизу — субтитры разговора) |
| `M` | Хозяйство (цены, запасы, казна) |
| `E` | Указы (подать, стража) |
| `R` | Развитие (жильё, стройки, здания, дерево развития) |
| `Y` | Торговля (вывоз/ввоз, караваны, склад) |
| `N` | Регион (угодья, угрозы) |
| `L` | свернуть/развернуть хронику |
| `T` | статистика и графики |
| `G` | Длань небес (бедствия и милости) |
| `O` | оверлей карты (преступность / риск пожара / богатство / угодья / плодородие / ресурсы) |
| `B` | панель строительства (каталог построек по категориям) |
| `R` в режиме стройки | повернуть здание (четыре стороны входа) |
| `Shift`+колесо в режиме стройки | размер кисти для зон (поле, пастбище, роща) |
| ЛКМ / протягивание в режиме стройки | поставить здание / провести дорогу или мост / закрасить зону / разметить жилой участок; ПКМ или `Esc` — отмена |
| `H` | камера на площадь |
| `Esc` | закрыть верхнее окно / снять выделение / отменить выбор цели |
| `Tab` | чистый экран (скрыть интерфейс) |

Интерфейс в духе CK3/HOI4: сверху полоса ресурсов с трендом за день и вложенными подсказками (наведите на строку «приход/расход» — раскладка по источникам), под ней тревоги (клик ведёт к месту), слева панель окон, справа «Обзор» (избранные ★, стройки, караваны, события), внизу хроника (сворачивается в строку), панель строительства и миникарта с оверлеями. Окна перетаскиваются, сворачиваются (▾) и закрепляются (📌); расположение запоминается. Настройки (⚙): масштаб интерфейса 80–150 %, пауза при событиях, субтитры, плотность облачков, уведомления.

Клик по жителю — пауза и карточка с вкладками: Обзор, Семья (родословное дерево), Отношения, Память, Приказы. Клик по зданию — карточка здания с управлением (нанять/уволить, предел рабочих, закрыть, приоритет, улучшить, снести; у стройки — срочно/пауза). Клик по событию в хронике или уведомлению — камера переносится к месту. Наведение на пустой тайл — подсказка о земле: угодье, плодородие, ресурс.

Строительство (панель внизу или `B`): постройка ставится призраком с подсветкой допустимых тайлов и радиусом влияния; казна платит монетами сразу, а доски и камень строители носят со склада, лесопилки и каменоломни по стадиям (фундамент → каркас → стены → крыша). Дороги рисуются линией (тропа бесплатна, мощёная — камень; через ручьи ложатся мосты), поля/пастбища/рощи — кистью, жилой участок размечает дома вдоль дороги. Очередь строек и приоритеты — в окне Развития. Снос возвращает половину материалов на склад.

Хозяйство (фаза 15): четыре десятка товаров по категориям (еда, сырьё, материалы, изделия, роскошь), промыслы в округе (лесорубы, охотники, рыбаки, собиратели, глина, руда, торф, соль, овцы, пасека, огороды), ремёсла второго уровня (кирпич, известь, крица, ткань, одежда, обувь, бочки, горшки, свечи). Городские хранилища — амбар, дровяной сарай, погреб — с вместимостью; носильщики свозят в них продукцию с производств. Еда портится (в амбаре и погребе медленнее, в погребе с солью — почти нет), в переполненном амбаре заводятся крысы. Зимой дома жгут дрова или торф, без топлива жильцы болеют; полоса ресурсов показывает запас дров в днях. Здания ветшают и чинятся материалами со склада за счёт казны. Книга учёта рынка сводит баланс каждого товара: произведено + куплено = потреблено + испортилось + продано + изменение запасов.

## Структура кода

- `src/core` — ГПСЧ, шум, время, математика
- `src/world` — тайлы, здания, генератор города (`generator.ts`) и ландшафта окрестностей (`landscape.ts`: высоты, притоки, озёра, болота, плодородие, месторождения, угодья, туман), A* с иерархическим HPA* для дальних путей (`pathfinding.ts`), пространственный хеш
- `src/sim` — ядро `Simulation` и подсистемы `sim/sub` (CityState, Economy, ConstructionSystem, Justice, Region); жители, население, расписание, движение, потребности, преступность, пожары, здоровье, погода, живность, события города, стройка и рост (`construction.ts`), божественные силы; природа (`nature.ts`: рубка и рост леса, запасы ресурсов, сезонные дары, дичь, туман), рудознатец (`prospect.ts`), заказ построек игроком (`build.ts`: размещение, дороги, зоны, участки, снос, улучшение, рабочие)
- `src/core/events.ts` — типизированная шина событий `sim.events`
- `src/data` — таблицы данных: профессии по зданиям, указы, дерево развития, каталог построек (`buildCatalog.ts`)
- `src/ai` — действия и utility-выбор, разговоры (`conversation.ts`, `talk.ts`), банк реплик (`dialogueData.ts`) и логика диалогов, приказы
- `src/economy` — товары (`goods.ts`: категории, порча, где хранятся), рецепты и промыслы (`production.ts`), рынок и книга учёта (`market.ts`), логистика (`logistics.ts`: вместимость хранилищ, носильщики, покупка дров, порча, крысы, отопление, износ и ремонт), деньги, налоги, торговля
- `src/events` — хроника
- `src/render` — камера, тайлы по чанкам, процедурные спрайты, освещение, погода, оверлеи, облачки (`bubbles.ts`, чистая раскладка `bubbleLayout.ts`)
- `src/ui` — стартовый экран с живой сценой (`startScene.ts`), система окон, верхняя полоса, левая панель, Обзор, карточки, панели, режим строительства (`buildMode.ts`) и панель построек (`buildbar.ts`), миникарта, субтитры, уведомления
- `src/save` — сериализация, цепочка миграций `MIGRATIONS`, IndexedDB, экспорт/импорт
- `test/headless.ts` — headless-тест; `test/fixtures` — старые сохранения для проверки миграций
