# Вальдмарк — живой средневековый город

Браузерная песочница-симулятор: средневековый город живёт сам по себе, а вы — невидимый наблюдатель с камерой, который может вмешиваться: отдавать приказы жителям и насылать бедствия. Полностью офлайн, один файл.

## Запуск

Откройте `dist/index.html` двойным кликом — сервер и интернет не нужны.

## Сборка из исходников

```
npm install
npm run build      # typecheck + сборка в dist/index.html
npm test           # headless-прогон симуляции (10 игровых дней на нескольких сидах) с проверкой инвариантов
DAYS=3 LARGE=1 npm test   # короче и с большим городом
npm run dev        # dev-сервер Vite
```

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` / стрелки / перетаскивание мышью | камера |
| колесо | зум |
| пробел | пауза |
| `1`–`4` | скорость 1×/2×/4×/8× |
| `F` | следовать за выбранным жителем (внизу — субтитры разговора) |
| `M` | Хозяйство (цены, запасы, казна) |
| `E` | Указы (подать, стража) |
| `R` | Развитие (жильё, стройки, здания, дерево развития) |
| `Y` | Торговля (вывоз/ввоз, караваны, склад) |
| `N` | Регион (угодья, угрозы) |
| `L` | свернуть/развернуть хронику |
| `T` | статистика и графики |
| `G` | Длань небес (бедствия и милости) |
| `O` | оверлей карты (преступность / риск пожара / богатство) |
| `H` | камера на площадь |
| `Esc` | закрыть верхнее окно / снять выделение / отменить выбор цели |
| `Tab` | чистый экран (скрыть интерфейс) |

Интерфейс в духе CK3/HOI4: сверху полоса ресурсов с трендом за день и вложенными подсказками (наведите на строку «приход/расход» — раскладка по источникам), под ней тревоги (клик ведёт к месту), слева панель окон, справа «Обзор» (избранные ★, стройки, караваны, события), внизу хроника (сворачивается в строку), панель строительства и миникарта с оверлеями. Окна перетаскиваются, сворачиваются (▾) и закрепляются (📌); расположение запоминается. Настройки (⚙): масштаб интерфейса 80–150 %, пауза при событиях, субтитры, плотность облачков, уведомления.

Клик по жителю — пауза и карточка с вкладками: Обзор, Семья (родословное дерево), Отношения, Память, Приказы. Клик по зданию — карточка здания. Клик по событию в хронике или уведомлению — камера переносится к месту.

## Структура кода

- `src/core` — ГПСЧ, шум, время, математика
- `src/world` — тайлы, здания, генератор города, A*, пространственный хеш
- `src/sim` — ядро `Simulation` и подсистемы `sim/sub` (CityState, Economy, ConstructionSystem, Justice, Region); жители, население, расписание, движение, потребности, преступность, пожары, здоровье, погода, живность, события города, стройка и рост, божественные силы
- `src/core/events.ts` — типизированная шина событий `sim.events`
- `src/data` — таблицы данных: профессии по зданиям, указы, дерево развития
- `src/ai` — действия и utility-выбор, разговоры (`conversation.ts`, `talk.ts`), банк реплик (`dialogueData.ts`) и логика диалогов, приказы
- `src/economy` — товары, рецепты, рынок, деньги, налоги, торговля
- `src/events` — хроника
- `src/render` — камера, тайлы по чанкам, процедурные спрайты, освещение, погода, оверлеи, облачки (`bubbles.ts`, чистая раскладка `bubbleLayout.ts`)
- `src/ui` — стартовый экран, система окон, верхняя полоса, левая панель, Обзор, карточки, панели, миникарта, субтитры, уведомления
- `src/save` — сериализация, цепочка миграций `MIGRATIONS`, IndexedDB, экспорт/импорт
- `test/headless.ts` — headless-тест; `test/fixtures` — старые сохранения для проверки миграций
